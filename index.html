Proof Of Work

Five scattered inputs, one error-checked payroll file every month.

Client details redacted pending sign-off

A multi-branch retail client was reconciling payroll by hand every month from WhatsApp messages, a shared spreadsheet, and a bank statement. We automated the consolidation — and while validating it against their own historical numbers, it caught a real commission-calculation error before it ever reached a payslip.

01

The problem

Attendance came in as free-text WhatsApp replies from branch managers, hours lived in a shared spreadsheet, and commission depended on manually reading a bank statement — including subtracting refunds by hand. Small, silent errors were easy to miss until a payslip was already wrong.

02

What we built

A structured intake pipeline that files each input the moment it arrives, one tested calculation module per source, and a hard rule: anything the system wasn't 100% certain about got flagged for human review — never silently resolved.

03

The result

The automation caught a discrepancy in one branch's revenue figure — worth real money in the monthly commission payout — invisible until checked against independently verified numbers.
